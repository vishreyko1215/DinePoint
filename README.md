# DinePoint

DinePoint is a Flutter-based restaurant discovery application designed to help groups find convenient places to eat by identifying a midpoint between different locations.

## Overview

Finding a restaurant that is convenient for everyone can be difficult when people are coming from different places. DinePoint addresses this problem by allowing users to find a midpoint between locations and explore nearby restaurants.

## Features

-  Find a midpoint between two locations
-  Discover nearby restaurants
-  Search and filter restaurants
-  View restaurant details
-  Save restaurants to favourites
-  View restaurants on a map
-  Share the midpoint location

## How It Works

1. Enter the locations of the people in the group.
2. DinePoint calculates a convenient midpoint.
3. Explore restaurants around the midpoint.
4. Apply filters to find suitable restaurants.
5. View restaurant details and location.
6. Save favourites or navigate to the restaurant.

## Technology Stack

- **Flutter**
- **Dart**
- **OpenStreetMap**
